# Phase 2.5 — Figures (opt-in: `--figures`)

The render → critique → fix loop. Off by default in `standard` tier. Figures
need the user's runtime Python; the pipeline probes and degrades honestly.

## 0. Probe

`python3 "${CLAUDE_PLUGIN_ROOT}/scripts/scholar.py" doctor --check-figures`.
If matplotlib is absent, tell the user; figures will deliver as spec + runnable
`.py` + caption (`render_status: deferred`) unless they `pip install matplotlib
pillow numpy` (+ system graphviz for schematics).

## 1. Anchored data files

For each planned figure, ensure `figures/<id>.data.json` exists with every datum
`{value, corpus_id, quote|page|section}` traceable to the corpus/evidence. For a
systematic review, generate the PRISMA flow deterministically:
`scholar.py emit-prisma --counts prisma-counts.json --format dot --out figures/prisma.dot`.

## 2. Design (parallel)

Spawn `intensive-research:ir-figure-designer` in ONE message (≤8 concurrent for
independent figures):
```
FIGURE: <id> — <kind: overview|results|prisma|forest>
DATA: figures/<id>.data.json    JOURNAL: <profile from figure-standards.md>
OUTPUT: figures/<id>.{py,pdf,png,meta.json}
When finished: figures/<id>.done
```

## 3. Critique (parallel)

When the `.done` markers exist, spawn `intensive-research:ir-figure-critic` in
ONE message over the rendered PNGs. Each writes `figures/<id>.critique.json`.

## 4. Loop

Read each `critique.json`. If `verdict: revise` AND `round < cap` (tier 1/2/3),
re-spawn the designer for that figure with the critique as input (fix only
flagged issues) and re-critique. Stop when `pass` or the cap is reached
(`render_status: needs_human`, figure still delivered with its open critique).

## 5. Manifest + gates

Write `figure-manifest.json` (per figure: id, kind, files, caption,
data_provenance, journal_profile, critic_verdict, render_status,
integrity_flags). Downstream:
- **G2**: `ir-claim-auditor` audits `figures/<id>.data.json` anchoring.
- **G3**: `scholar.py audit-report report.md --corpus corpus.json --figure-manifest figure-manifest.json`.
- **G4**: `readiness --figure-manifest figure-manifest.json` fails if a
  `deferred`/`needs_human`/`revise` figure is embedded as a rendered result.

Send finished figures to the user with `SendUserFile` (vector master + PNG proof).
